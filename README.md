# Data-Science-Final-Project
## Air Pollutant Emission Prediction in the United Kingdom Using Machine Learning
Dataset Used: Air Quality and Emissions Dataset (https://naei.energysecurity.gov.uk/air-pollutants/air-pollutant-emissions-data).

Dataset Contains: Information about different gas types, emission values (kilotonnes), emission sources, activities, and years. It provides data for exploring emission patterns across different categories and time periods.

Dataset collected from: The greenhouse gas data was collected by the UK National Atmospheric Emissions Inventory (NAEI). It includes yearly emission data from 1990 to recent years. The data covers pollution produced across the United Kingdom from different sectors and industry for official government reporting.

Exploratory Data Analysis (EDA): The project uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn to understand and analyse the dataset. Data cleaning is performed by handling missing values and removing unnecessary columns. EDA includes analysing average emissions by gas type, identifying the top 10 emission sources and activities, examining yearly emission trends, and visualising correlations between year and emission using a heatmap.
